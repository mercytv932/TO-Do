✅ To-Do App
Overview

A dynamic task management application that allows users to create, edit, complete, and delete tasks.

✨ Features
Add tasks
Delete tasks
Edit tasks
Mark tasks as completed
Task counter
Keyboard Enter support
Dynamic UI rendering
🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
📚 Concepts Practiced
Dynamic element creation
Arrays and loops
Event listeners
Class toggling
DOM rendering
State management
🚀 Goal

This project was built to improve my JavaScript logic, DOM manipulation skills, and understanding of interactive frontend behavior.
